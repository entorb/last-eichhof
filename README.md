# Last Eichhof Remake

Remake of the 1993 MS-DOS game **The Last Eichhof** in modern web tech stack

Hosted at [entorb.net/last-eichhof/](https://entorb.net/last-eichhof/)

Installable as a PWA and fully playable offline after the first load (`vite-plugin-pwa` precaches every asset; icons generated by `scripts/gen-icons.mjs`). The service worker is only generated by `pnpm run build`; test it with `pnpm preview` (service workers need localhost or HTTPS).

## Tech Stack

- TypeScript
- Phaser V4

### Tech Stack preparation steps

- `pnpm create @phaserjs/game@latest`
- `pnpm self-update`
- `pnpm approve-builds`
- `pnpm run dev`
- `pnpm add -D @biomejs/biome`
- `pnpm exec biome init`
- `pnpm exec biome check --write`

## Commands

- `pnpm dev` — dev server (<http://localhost:5173/last-eichhof/>)
- `pnpm run build` — production build to `dist/`
- `pnpm preview` — serve the production build locally
- `pnpm test` — vitest
- `pnpm run lint` — biome
- `pnpm run icons` — regenerate `public/icons/` + `public/favicon.png` from `scripts/gen-icons.mjs` (committed, not run on build)

## Graphics

Two skins, switchable in the start screen, OPTIONS and the pause overlay (`GRAPHICS: MODERN` / `GRAPHICS: ORIGINAL`):

- **MODERN** (default) — new vector art drawn with Canvas2D: smooth gradient glass, glows and anti-aliased edges, but the same beer-bottle subject matter as the original.
- **ORIGINAL** — the 1993 DOS sprites extracted from `BEER.DAT`.

`/last-eichhof/skins.html` (dev server only) lists every texture with the DOS art beside the modern art.
